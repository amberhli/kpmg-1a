# 🤖 kpmg-1a: Measuring the Impact of AI

## Project Overview

This repository houses the code, data, and notebooks for the project focused on **Measuring the Impact of AI on Productivity, Sustainability, and Energy Optimization** in commercial and residential buildings.

This initiative is a collaboration to explore how machine learning models and data-driven insights can inform energy-saving strategies, operational efficiency, and environmental impact reduction.

---

## 🎯 Goals

The primary objectives of this project are to:

* **Productivity:** Analyze and model the effect of AI-driven optimization on building operational efficiency (e.g., HVAC system performance, maintenance cycles).
* **Sustainability:** Quantify the reduction in the **carbon footprint** achieved through intelligent energy management.
* **Energy Optimization:** Develop and test **machine learning models** to predict energy consumption and identify opportunities for automated, real-time energy savings.

---

## 📁 Repository Structure

The project is organized into the following key directories and files:

| Folder/File | Description |
| :--- | :--- |
| `data/` | Contains the raw and processed datasets used for training and testing models. |
| `notebooks/` | Jupyter Notebooks (`.ipynb`) for data cleaning, exploratory data analysis (EDA), model development, and results visualization. |
| `up15-ny-largeoffice.csv` | Example dataset for a New York large office building (Upstream Project 15). |
| `up4-ny-largeoffice.csv` | Example dataset for a New York large office building (Upstream Project 4). |
| `requirements.txt` | Lists all necessary Python packages and their versions to reproduce the project environment. |
| `.gitignore` | Specifies intentionally untracked files to ignore (e.g., temporary files, environment variables). |
